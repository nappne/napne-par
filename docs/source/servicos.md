# Serviços

O NAPNE oferece diversos serviços para apoiar a comunidade acadêmica:

## Atendimento Educacional Especializado

- Acompanhamento pedagógico individualizado
- Adaptação de materiais didáticos
- Orientação para professores
- Suporte tecnológico assistivo

## Acessibilidade

### Física
- Avaliação de barreiras arquitetônicas
- Orientação sobre adaptações no campus
- Acompanhamento de obras de acessibilidade

### Digital
- Suporte para tecnologias assistivas
- Adaptação de conteúdos digitais
- Capacitação em ferramentas acessíveis

## Capacitações

- Cursos de Libras
- Workshops sobre inclusão
- Formação continuada para servidores
- Sensibilização da comunidade acadêmica

## Como solicitar atendimento

1. Procure o NAPNE pessoalmente
2. Entre em contato por e-mail
3. Ligue para nosso telefone
4. Participe de nossas reuniões abertas

```{warning}
Todos os atendimentos são gratuitos e confidenciais.
```
